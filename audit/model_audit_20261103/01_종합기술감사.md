## 1. 현재 시스템 구조와 작동 방식

```
[PC 작업 스케줄러 07:30] run_daily.py
  collect(): WAMIS 원대교 일유량·시간수위 / 기상청 AWS 일강수(321·557·559)·인제 기온·23시 단기예보·특보 / 물모아 SS → data/live/
  assemble(): base_inputs(2014-01-22~2026-08-26) + live → 일별 표 (P0 티센, Q=원대교×1.0414, Havg/Hmax/Hmin, TAMAX/TAMIN, 10시 시간수위 7변수, SS)
  model.estimate(): features()[연도별 수위–유량식 보정 → 37변수] → Blend(XGB 10시드 평균 + SafeRidge, log 평균) + 내부 3겹 잔차 중앙값 보정
                    → 전체 실측으로 매일 재학습 → 모든 날짜 추정 + 고정 로그잔차 80% 구간(LOG_LO/HI)
  Forecaster: 기준일 D의 관측 변수 17개(+기온 3) [+ Pfut=log1p(ΣP D+1..D+h), Pfut_max]
     hindcast(): 2019년 이후 매 기준일, 그 해 이전 실측으로 학습(연도별) → docs/forecast_daily.csv
                 '예보강우' 열은 실제 내린 비를 대입(실제 강우 대입)
     live(): 마지막 기준일, 전체 실측 학습 → 관측만 / 0–120 mm 시나리오 / 기상청 예보(있는 날만 합산)
  locked_eval(): ≤2026-08-26 실측으로 학습해 이후 실측 채점(현재 0건)
  build(): 성능표·구간폭은 forecast_static.json(2019–26 전진검증 고정값) → docs/index.html 등
```

- 학습 표본은 SS 493건(2014–2026, 연 36–41건, 간격 중앙 7일)입니다. 전진검증 시험 표본은 2019–26 295건입니다.
- 모델 크기: XGB(depth 3, 300 트리) × 10시드 + Ridge이고, 내부 보정용으로 3겹을 다시 학습합니다. 학습 1회에 Blend 4번(XGB 40개)이 돕니다.

## 2. 잘된 점 (유지 권장)

1. 표본외 평가를 분리했습니다. 일별 전진검증 점(◇)을 표본내 추정선과 따로 표시하고, "표본 내라 잘 맞아 보인다"고 안내합니다.
2. 예측의 기준일과 목표일 정렬이 정확합니다. `f.shift(h)`, Pfut 창 D+1..D+h를 확인했습니다. 미래 창 rolling 같은 직접 누수는 없습니다.
3. Ridge 외삽에 안전장치가 있습니다. 입력을 학습 범위로 자르고 출력을 최대 실측×2로 제한해, 미채수 홍수일 폭주를 막습니다.
4. 성능표에 "+예보강우*"가 실제 강우 대입 가정이라는 각주가 있습니다.
5. 잠금평가 구조(2026-08-26 기준)가 이미 있습니다.
6. 변수 묶음마다 성능 기여가 확인됩니다. 과적합 신호는 없습니다(05 문서 2절).

### B. 고농도 SS 과소예측 — 확인
1. SS 분포: 중앙 1.9, P90 9.6, 최대 276 mg/L입니다. ≥10은 49건(9.9%), ≥25는 18건(3.7%), ≥100은 2건입니다.
2. 성능 (일별 전진검증):

   | 구간 | n | MAE | 예측/실측 중앙비 |
   |---|---|---|---|
   | SS≥10 | 30 | 21.7 | 0.64 |
   | SS≥25 | 13 | 42.4 | 0.41 |
   | 상위 10%(≥10.3) | 30 | ≥10과 같음 | — |
   | SS<10 | 265 | 0.83 | 1.17 |

   1일 예측의 SS≥25 중앙비는 0.25(관측만)·0.35(실제 강우 대입)이고, 3일은 0.08·0.17입니다.
3. 원인 분석:
   - XGB 외삽 한계: 트리는 학습 최대 범위 밖을 예측하지 못합니다. SS≥25에서 XGB 로그 오차 1.15, Ridge 1.32로 둘 다 큽니다.
   - Ridge 혼합: 원척도 과소를 완화합니다(MBE −1.84 → −1.60).
   - 로그변환: 기하평균 회귀라 양쪽 끝이 중앙으로 당겨집니다.
   - 중앙값 보정: 영향이 없습니다(보정 없음 0.761). Duan 평균 보정은 고농도에 유리하지만 평상시를 망칩니다(0.697).
   - 입력 부족(일 강우량, 일평균 유량): 2021-03-03은 어떤 입력에도 신호가 없습니다.
4. 대안 비교(`r4`): 고농도 가중, Tweedie 원척도 손실, 2단계 모두 SS≥25 중앙비 0.38–0.44로 개선이 없습니다. 2단계는 평상시 MAE를 0.83에서 0.97로 악화시킵니다. **자료 범위·해상도 문제이지 손실함수 문제가 아닙니다.**
5. 연도·사상 집중: ≥25 사상은 연 0–3건으로 고르게 퍼져 있습니다. 다만 시험 MAE는 2023년(276 사상) 7.28로, 한 사상이 연 성능을 결정합니다.

## 5. 최종 결론 — 10개 질문에 대한 답

1. **현재 예측성능은 얼마나 신뢰할 수 있는가?**
   - 일별 추정의 로그R² 0.76과 MAE 2.9는 재현되었습니다. 라벨 누수가 없으니 "평상시 농도 수준"을 맞히는 능력은 신뢰할 수 있습니다. 다만 같은 기간으로 모델을 골라 0.01–0.03 낙관적일 수 있습니다(가정).
   - 1일 예측(0.70–0.75)은 실제 예보를 써도 유지됩니다.
   - 3일은 실제 예보 기준 약 0.60입니다(실제 강우 대입 0.63–0.65).
   - 7일은 월 평균보다 실질적으로 낫지 않습니다.
   - 고농도(≥25)는 모든 경우 실측의 8–41%만 예측합니다.
2. **검증방법의 구조적 한계는?** 선택·보고·구간 보정이 한 표본(2019–26)에서 이루어졌습니다. 예보강우가 실제 강우 대입이고, 고농도 표본은 13건뿐입니다. 공개 지연 무시는 구조적 결함이지만, 실험상 성능 영향은 없었습니다(|Δ| ≤ 0.006).
