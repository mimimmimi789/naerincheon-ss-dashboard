# 04. 개선 실험 계획 (2026-11-03)

원칙은 다섯 가지입니다.
1. 한 번에 하나만 바꿉니다.
2. 모든 비교는 같은 시험 날짜, 같은 입력 가용성 조건에서 합니다.
3. 원척도와 로그척도를 함께 봅니다.
4. 월 블록 부트스트랩 95% 구간을 냅니다.
5. 모델 선택에 쓴 기간을 독립시험이라고 부르지 않습니다.

이번 감사에서 실제로 돌린 실험은 "실행" 열에 결과 파일을 적었습니다. 돌리지 않은 것은 **미실행**으로 표시했습니다.

## 0. 공통 평가체계 (Phase 2 설계)

| 구분 | 내용 |
|---|---|
| 기준시점 t | 예측: 기준일 D 24시(운영은 다음날 07:30 실행). 일별 사후추정: 해당 날짜 전체 자료 사용 가능(사후). |
| 입력 가용성 | 강우·유량·수위·기온은 D까지 확정(유량 잠정값 정정 이력은 없음, **가정**). 예보는 D 23시 발표본. SS 라벨은 **채수일 ≤ t − L**만 학습에 사용합니다. 공개 이력이 없어 L = 60일을 기본으로 두고, 0일과 120일로 민감도를 봅니다(관측일을 공개일로 간주하지 않음). |
| 전처리 | 수위–유량식, 보간, 대체값, 보정값은 기준시점 이전 자료로만 만듭니다. 현재 위반 항목: 그해 전체로 적합하는 수위–유량식, 양방향 보간(기온 3일·시간수위 6시간), 2019–26 같은 표본으로 정한 구간폭. |
| 분할 | (1) 개발: 2014–2022 안에서 확장 창 전진검증(2019–2022 각 연도)으로 변수·모델·하이퍼파라미터를 선택합니다. (2) 준독립 확인: 2023–2025. 기존 운영 모델은 이미 2019–26을 보고 골랐기 때문에 이 구간도 진짜 독립은 아닙니다. 새 후보끼리 비교할 때만 씁니다. (3) **진짜 독립시험: 2026-08-27 이후 새 실측(잠금평가).** 이 날 이후 모델 구조와 변수를 바꾸지 않습니다. |
| 재학습 | 시험은 분기별 재학습(as-of, L 지연)과 연도별 재학습 두 방식을 함께 보고합니다. |
| 선행기간 간격 | h일 예측 학습 행의 목표일 T는 t − L 이하여야 합니다. L ≥ 60 > h라서 추가 간격(gap)은 따로 둘 필요가 없습니다. |
| 지표 | 로그R²(아래 정의), 원척도 R², MAE, RMSE, 로그 RMSE, MedAE, MBE, SS≥10·≥25 MAE, 예측/실측 중앙비, 10·25 mg/L 초과 재현율·정밀도, SS<10 MAE. 구간: 포함률(전체, 농도별, 강우별), 평균 폭. |
| 통계 | 월 블록 부트스트랩(1,000–2,000회) 95% 구간. 강우사상 단위 블록은 미실행(사상 정의 필요). |
| 판정 | **Pareto 기준:** 로그R²와 MAE 중 하나가 유의하게 좋아지고 다른 하나가 나빠지지 않으면서, SS≥25 중앙비와 SS<10 MAE가 미리 정한 허용폭(중앙비 −0.05, SS<10 MAE +0.05 mg/L) 안이어야 채택합니다. 같으면 단순한 쪽을 고릅니다. |

로그R² 정의: R²_log = 1 − Σ(ln y − ln ŷ)² / Σ(ln y − mean(ln y))². y·ŷ는 mg/L이고 0 이하는 없습니다(SS>0만 사용). 원척도 R²는 같은 식에 y, ŷ를 넣습니다.

## 1. 개선 후보별 계획

### P0-1. 예보강우 평가 분리 (과제 A·K)
1. 기존 구현: 학습과 hindcast에 실제 내린 비(완벽예보)를 넣습니다. 운영에는 기상청 예보를 넣고, 7일은 5일치만 넣습니다.
2. 검증된 문제: 성능표의 "+예보강우"는 완벽예보 사후평가입니다. 보관본 실제 예보로 다시 평가하면 1일은 거의 같고(0.749 vs 0.753), 3일은 앞 2일 예보만으로 0.599(완벽 0.648)입니다. 7일은 2일 예보 0.288로 관측만(0.383)보다 나쁩니다.
3. 원인: 예보 기간이 모자라면 부족한 날이 0 mm로 들어갑니다. 예보의 강도 오차(10 mm 이상 예보 38회 중 실제 10 mm 이상 16회)도 있습니다.
4. 대체 방법: (a) 성능표를 "완벽예보(사후)"와 "실제예보(보관본)"로 나눕니다. (b) 예보 충족률이 h 미만이면 "기상청 예보" 대신 관측만 결과를 주 값으로 보여 주고, 예보 반영값은 "부분 예보(5/7일)"로 표시합니다. (c) 부족한 날을 월별 기후 강우 기대값으로 채우는 시나리오. (d) 학습도 보관 예보로 하는 모델(2014–2024 예보 약 1,100건).
5. 실험: 같은 날짜(보관본 있는 날)에서 관측만 / 완벽 / 실제예보 / 실제예보+기후 채움 / 예보로 학습한 모델을 비교합니다.
6. 지표: 공통 지표와 MBE(과소예측)입니다.
7. 장점과 위험: 실제 성능을 정직하게 표시할 수 있습니다. 위험은 보관본이 1·2일까지만 완전하다는 점입니다(3일 이후 부족).
8. 도입 기준: (a)(b)는 근거가 이미 있어 바로 도입합니다. (c)(d)는 실제예보 조건에서 로그R²와 MBE가 모두 나아질 때만 도입합니다.
- 실행: (a)의 근거 실험은 실행했습니다(`r1_scores.csv`). (c)(d)는 **미실행**입니다.

### P0-2. as-of(공개 지연) 평가 (과제 C6·D·M)
1. 기존 구현: 연도별로 학습합니다(그해 1월 1일 이전 실측 전부 사용). 공개 지연은 무시합니다.
2. 검증된 문제: 1–2월 기준일에는 공개 전인 11–12월 라벨을 씁니다(낙관적). 연말 기준일에는 1년 가까이 된 모델을 씁니다(보수적). 실제 공개 이력이 없습니다.
3. 대체 방법: 분기별 재학습, 학습 라벨은 채수일 ≤ t − L(L = 0/60/120)로 제한합니다.
4. 결과: `r7b_same_days.csv`(05 문서 4절). 연도별 방식과 차이 |Δ로그R²| ≤ 0.006입니다. 3·6·9·12월은 분기 창 버그로 미평가입니다.
5. 도입 기준: 결과가 같으므로 성능 수치는 그대로 두고, "공개 지연 0–120일 가정에서도 같음"이라는 주석만 붙입니다. 전체 월 재실행은 P1입니다.

### P0-3. 수위–유량식 as-of (과제 C1·I8)
- 시험연도 행은 직전 2년 자료로 적합한 식을 씁니다. 결과는 `r4_scores.csv`의 "수위–유량식 as-of" 행입니다.
- 도입 기준: as-of 성능이 운영과 같은 수준(Δ 로그R²의 95% 구간이 0 포함)이면 운영식을 "기준일 이전 365일 적합"으로 바꿉니다. 그래야 운영 결과가 재현 가능하고 과거 값이 매일 바뀌지 않습니다.

### P0-4. 예측구간 재보정 (과제 J)
1. 기존 구현: 2019–26 전진검증 로그 잔차의 10–90% 분위수(고정 폭)입니다. 같은 표본에서 포함률 79.7%를 보고했습니다.
2. 검증된 문제: 같은 표본에서 정했으므로 전체 포함률 80%는 당연한 결과입니다. 시간순 보정(이전 연도 잔차만)으로는 일별 75.7%입니다. 조건부로는 SS≥25에서 33–42%, 3·7일 예측의 SS≥25에서 0–8%입니다.
3. 대체 방법: (a) 시간순 분할 conformal(잔차는 기준일 이전 것만). (b) 강우·유량 상태별(예: 기간 강우 ≥10 mm) 분리 분위수, 즉 Mondrian conformal. (c) 구간 하한만이 아니라 "고농도 가능성" 보조 표시.
4. 지표: 조건별 포함률과 평균 폭입니다.
5. 도입 기준: 시간순 평가에서 전체 포함률이 75–85%이고, 강우 ≥10 mm 조건 포함률이 개선되어야 합니다. 문구는 "과거 오차 기준 약 80%(고농도에서는 더 낮음)"로 바꿉니다.
- 실행: 진단만 실행했습니다(`r5_interval.csv`). (b)는 **미실행**입니다.

### P1-1. 강우 결측 처리 (과제 H)
- 변경: 기린 결빙 기간(2023-01-01~03-22, 2016-12-21)을 결측으로 두고 재정규화합니다. 결측일을 0으로 바꾸지 않고 NaN을 유지합니다(rolling `min_periods`를 창 길이로).
- 실험: 원자료는 보존하고 변환 전후 일별·1·3일 전진검증을 비교합니다. 유효 표본수 변화도 보고합니다.
- 도입 기준: 성능이 나빠지지 않으면 도입합니다(물리적 정합성 개선이 목적).
- **미실행**: PC 원자료가 필요합니다.

### P1-2. 변수 정리 (과제 G)
- 결과: `r4_scores.csv` M0–M5(05 문서 2절).
- 도입 기준: 축소안이 운영과 같은 수준이면(구간이 0 포함) 단순한 쪽을 채택합니다. 고농도 지표가 나빠지면 채택하지 않습니다.

### P1-3. 앙상블 단순화 (과제 F)
- 결과: XGB 10시드와 1시드의 차이는 유의하지 않습니다. Ridge 혼합은 원척도 R²·편향에 도움이 됩니다. 혼합비 0.5를 중첩 선택했을 때 이득이 없었습니다.
- 계획: 시드 수를 10에서 3으로 줄이는 것은 계산 시간만 줄이는 선택입니다. 성능 근거로는 바꾸지 않습니다. 잠금평가가 끝날 때까지 운영 구조는 그대로 둡니다.

### P1-4. 고농도 대응 (과제 B·N)
- 비교안은 다섯 가지입니다: 가중 학습, Tweedie(원척도) 손실, 2단계(분류×조건부 회귀), 강우강도·첨두수위 변수, 구간 보정. 결과는 `r4_scores.csv`에 있습니다.
- 위험: SS≥25 학습 표본이 연도별 확장 기준 6–17건뿐입니다. 2단계 모델은 과적합 위험이 큽니다.
- 도입 기준: SS<10 MAE 악화가 +0.05 mg/L 이내이고 로그R² 하락이 0.01 이내여야 합니다. 그 조건에서 SS≥25 중앙비가 0.1 이상 오르면 도입합니다.
- 추가 자료 후보(효과가 가장 클 것으로 예상): 시간 강우강도(AWS 분자료), 원대교 시간 유량, 탁도(취수장)가 있습니다. 모두 **미실행**입니다.

### P1-5. 목표 정의 분리 (과제 N)
- "h일 뒤 농도"와 "h일 안 최대 농도 / 기준 초과 확률"을 분리합니다. 초과 확률은 로지스틱 보조 출력으로 하고, 평가는 채수일에서만 합니다(미채수일은 평가에서 뺍니다).
- **미실행**입니다.

### P2. 기타
- 공개일 이력 수집: 물모아 갱신일을 매일 기록하도록 `run_daily`에 추가합니다(새 실측이 처음 보인 날 = 공개일).
- 모델 카드(버전, 학습 종료 채수일, 데이터 공개일, 입력 최신일, 생성일)를 `latest.json`에 넣습니다.
- 하천 거리 기반 지연 재평가, 티센 GIS 재계산, 소양강댐 유입량과 유량 대조를 합니다.
